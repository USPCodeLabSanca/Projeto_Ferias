aprendizados para guardar no coração:
    -verifique se a permissão para editar arquivos é suficiente pro código q você está executando
        -caso não, usa o chmod

    -para problemas com o nodemon, pq VAI ter vários:
        -para testar sem ele, é só dar "node index.js" no terminal
        -se o servidor estiver dando "nodemon clean exit", tenta mudar a porta de entrada
        -para deletar a pasta node_modules, usa "sudo rm -rf node_modules" no terminal
        -no package.json, o seu script tem que ser assim:
        
            "scripts": {
                "start": "nodemon index.js",
                "dev": "nodemon --delay 0.5s --ignore 'erros.json' --ignore 'validos.json' index.js"
            },
